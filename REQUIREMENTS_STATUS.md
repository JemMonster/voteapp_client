## 3. Требования к поисковой строке

### 3.1 Кнопка "Очистить"
**Требование:** На поисковой строке должна быть реализована кнопка "Очистить".

✅ **Выполнено** — кнопка отображается в trailingIcon OutlinedTextField.

### 3.2 Подсказка (placeholder)
**Требование:** В поле ввода поискового запроса отображается подсказка, если поле ввода пустое.

✅ **Выполнено** — placeholder: "Введите запрос для поиска..."

### 3.3 Появление клавиатуры
**Требование:** При нажатии на поле ввода появляется клавиатура.

✅ **Выполнено** — используется FocusRequester для автоматического фокуса.

### 3.4 Отображение кнопки "Очистить" при наличии текста
**Требование:** Если в поле ввода поискового запроса введён какой-то текст, то отображается кнопка "Очистить".

✅ **Выполнено** — условие `if (state.query.isNotEmpty())` контролирует отображение.

### 3.5 Скрытие кнопки "Очистить" при пустом поле
**Требование:** Если в поле ввода поискового запроса нет никакого текста, то кнопка "Очистить" не отображается.

✅ **Выполнено** — кнопка скрыта через условный рендеринг.

### 3.6 Действие кнопки "Очистить"
**Требование:** Нажатие на кнопку "Очистить" удаляет текст в поле ввода поискового запроса и скрывает клавиатуру.

✅ **Выполнено** — `clearQuery()` очищает текст, `focusManager.clearFocus()` скрывает клавиатуру.

## 4. Сохранение состояния

### 4.1 Сохранение текста при повороте устройства
**Требование:** Необходимо реализовать сохранение текста поискового запроса в жизненном цикле, то есть если в поле ввода поискового запроса есть какой-то текст, то при повороте устройства в ландшафтную ориентацию и обратно текст в поле ввода поискового запроса не исчезает.

✅ **Выполнено** — состояние хранится в StateFlow внутри ViewModel, которая автоматически сохраняется при конфигурационных изменениях.

---

## 5. Плейсхолдеры

### 5.1 Плейсхолдер "Нет результатов"
**Требование:** Необходимо реализовать плейсхолдер, если нет результатов поиска.

✅ **Выполнено** — `NoResultsPlaceholder()` компонент с иконкой 🔍 и сообщением "Ничего не найдено".

### 5.2 Плейсхолдер ошибки с кнопкой "Обновить"
**Требование:** Если поисковый запрос завершился неудачно, плейсхолдер должен содержать кнопку "Обновить", также необходимо реализовать повторное отправление последнего запроса при нажатии на нее.

✅ **Выполнено** — `ErrorPlaceholder()` компонент с иконкой ⚠️, сообщением об ошибке и кнопкой "Обновить", которая вызывает `retrySearch()`.

## 6. История поиска

### 6.1 Отображение истории при нажатии на поисковую строку
**Требование:** При нажатии на поисковую строку пользователь должен видеть историю поиска (при условии, что у пользователя непустая история и он не очищал историю поиска).

✅ **Выполнено** — при фокусе на поисковую строку отображается выпадающий список с историей.

### 6.2 Максимум 10 элементов
**Требование:** В истории должно храниться не больше 10 элементов.

✅ **Выполнено** — в `SearchViewModel.addToHistory()` реализовано ограничение `if (currentHistory.size > 10)`.

### 6.3 Добавление в историю при выборе
**Требование:** Нажатие на элемент в списке результатов поиска добавляет его в историю.

✅ **Выполнено** — `selectFromHistory()` добавляет выбранный запрос в историю.

### 6.4 Порядок хранения
**Требование:** Элементы хранятся в истории в порядке добавления (новые отображаются в верхней части списка).

✅ **Выполнено** — новые элементы добавляются в начало списка через `currentHistory.add(0, query)`.

### 6.5 Очистка истории
**Требование:** Нажатие на кнопку "Очистить историю" полностью очищает записи истории поиска.

✅ **Выполнено** — кнопка "Очистить историю" вызывает `clearHistory()`.

## 8. Тёмная тема

### 8.1 Переключатель темной темы
**Требование:** Необходимо реализовать переключатель темной темы.

✅ **Выполнено** — реализован через:
- `ThemeManager` — управление состоянием темы через DataStore
- `ThemeViewModel` — ViewModel для управления темой
- `VoteAppTheme` — поддержка параметра `darkTheme`
- Переключатель на экране ленты (в TopAppBar)
- Переключатель на экране профиля (карточка с настройками)

### 8.2 Сохранение выбора темы
**Требование:** Выбор темы должен сохраняться между сессиями приложения.

✅ **Выполнено** — используется Android DataStore для хранения предпочтений пользователя.
